Drag the photo anywhere on the box to reposition it. When selected, drag its four corner handles (or use the corner fields below the stage) to pin each corner independently — this fakes real perspective when the box surface isn't flat-on to the camera (e.g. a tilted lid or an angled photo), which a simple skew can't do. The warp is emitted as a CSS matrix3d() on the photo, plus the corner offsets (in px, relative to the rendered box size) in the JSON so you can recompute it if you resize. top/left are still percentages relative to the box container.
